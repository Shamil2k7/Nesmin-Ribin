## ✨ Features

- **Cinematic Invitation Reveal:** Interactive envelope opening ceremony with Arabic Bismillah calligraphy, English translation, and botanical line illustrations.
- **Official Invitation Card Showcase:** Full vertical uncropped stationery display with responsive scaling and click-to-expand lightbox zoom.
- **Audio Experience:** Integrated player for *"Aaj Sajeya"* with play/pause controls, volume envelope, and animated visualizer bars (no autoplay).
- **Floating Venue Location Action:** Pinned floating button connecting guests directly to Google Maps navigation.
- **Live Countdown:** Real-time countdown timer to 29 November 2026.
- **Save The Date & Interactive Map:** Embedded Google Maps preview with "Add to Google Calendar" shortcut.
- **Family Blessings:** Responsive family tree layout.
- **Custom N&R Monogram Favicon:** Crisp vector and ICO branding.
- **100% Mobile Responsive:** Optimized for WhatsApp sharing and mobile displays.

## 🛠 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Styling:** Tailwind CSS & Vanilla CSS Variables
- **Animations:** GSAP & ScrollTrigger
- **Icons:** Lucide React
- **Typography:** Cormorant Garamond, Playfair Display, Amiri, Inter (via Next.js Font Optimization)

## 🚀 Getting Started

### 1. Install dependencies
```bash
npm install
```

### 2. Run local development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

---

## ☁️ Deploy on Vercel

1. Import this repository into [Vercel](https://vercel.com/new).
2. Framework Preset: **Next.js**.
3. Build Command: `npm run build` (or Next.js default).
4. Output Directory: `.next` (default).
5. Click **Deploy**.
